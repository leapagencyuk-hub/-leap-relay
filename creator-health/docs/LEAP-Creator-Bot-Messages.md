# LEAP bot — creator messages

Six messages. Every one ends with a route to support, because the point of a
notification is to start a conversation, not to inform somebody they are
failing.

Placeholders in `<>` are filled by the bot. Channel names need swapping for
whatever yours are actually called.

## NOTES

**Day 20 needs both versions.** At day 20 there are only 10 days left, so a
creator on 0 days needs all 10. Version B says that plainly instead of
cheerleading. A message that tells somebody an impossible thing is achievable
is the fastest way to lose their trust, and they will remember it when the
removal lands.

**Suggested split:** Version A at 2-4 days, Version B at 0-1.

**The day 80 message makes an algorithm claim** — that TikTok favours LIVEs
which hold an audience. That is standard coaching advice and widely accepted,
but it is not something LEAP's own data proves. If you would rather not assert
it, cut the middle paragraph and leave the stream review offer, which stands on
its own.

**Every message routes to #support rather than naming a person to DM.** A
ticket gets picked up by whoever is around; a DM sits unread if that coach is
asleep. It also means you can see which messages actually generate
conversations, which is the only way to find out whether any of this works.
